Wine is one of the world’s most celebrated drinks, but not all wines are created equal. Their quality depends on a delicate balance of chemical properties such as acidity, sugar, pH, and alcohol content.

This project explores how these physicochemical properties influence the quality of red wine, and whether we can predict wine quality using data-driven insights.

## Dataset

- **Source**: [UCI Machine Learning Repository – Wine Quality Dataset](https://archive.ics.uci.edu/ml/datasets/Wine+Quality)
- **Description**: Contains physicochemical test results for red wine samples, including:
  - Fixed acidity
  - Volatile acidity
  - Citric acid
  - Residual sugar
  - Chlorides
  - Free sulfur dioxide
  - Total sulfur dioxide
  - Density
  - pH
  - Sulphates
  - Alcohol
  - Quality (target label)

## Why This Project?

The goal is to uncover patterns in wine chemistry that separate a high-quality wine from a lower-quality one.
By analyzing the data, we gain insights into which features — like alcohol or acidity — play the biggest role in shaping wine quality.

## Model Used
